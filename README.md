# In-App Template Gallery — CleverTap Custom HTML

178 production-ready Custom HTML in-app templates across 11 categories, with live phone-mockup previews, an editable CONFIG per template, auto-listed CleverTap events, implementation guides, and copy-ready code. Includes hover quick-previews, light and dark modes, and links to all seventeen galleries in the Field Guide Family.

**Live:** https://shijunneo-bot.github.io/ct-template-gallery/

## Updating the site (GitHub website, no terminal)
1. **Add file → Upload files** on the repo page.
2. Drag in the changed files (`index.html`, and any of `og-image.png`, `robots.txt`, `sitemap.xml`, `llms.txt`, `README.md`) → commit.
3. Template files live in `templates/` — always upload new templates **from inside that folder** so they land in the right place.
4. GitHub Pages redeploys within a minute or two.

## What's in this repo
- `index.html` — the gallery: browse, search, hover quick-preview, phone/web-pop-up preview, CONFIG customiser, events, guides, light/dark mode, Field Guide Family navigation.
- `templates/` — one self-contained HTML file per template.
- `og-image.png` — social share card (1200×630).
- `robots.txt`, `sitemap.xml` — search engine plumbing.
- `llms.txt` — a plain-language map of the gallery for AI assistants and answer engines.
